# RELATIVE BUY BOLL 中轨斜率过滤候选设计

## 1. 候选身份与研究问题

- 候选 build：`20260901.3`。
- 直接基线：commit `adcb020`、build `20260828.5`。
- 唯一研究问题：只允许 T-1 归一化 BOLL 中轨斜率不小于 0 的
  `RELATIVE BUY` 进入空位补位队列，能否改善真实交易路径的收益、胜率、回撤和利润
  分散度。
- 本候选不叠加量比优先级、全三指标组合或其他实验。

本地归因和模拟只用于提出候选。最终表现必须以聚宽 2019--2021 训练期完整回测为准。

## 2. 单变量资格规则

对已经由 build `20260828.5` 生成的每个 `RELATIVE BUY`，从同一份冻结 T-1 信号
快照读取：

```text
normalized_boll_mid_slope = boll_mid_slope / close
```

其中 `boll_mid_slope` 是 T-1 BOLL 中轨相对上一完整交易日的差值，`close` 是 T-1
收盘价。唯一阈值固定为自然边界 `0.0`，不搜索其他阈值。

| 输入状态 | RELATIVE 新买入资格 | 空位影响 |
| --- | --- | --- |
| 有限且 `normalized_boll_mid_slope >= 0` | 保留 | 后续沿用既有排序和下单语义 |
| 有限且 `< 0` | 拒绝 | 排序前移除，不消耗空位 |
| 斜率缺失、不可转为数值或非有限 | fail-closed 拒绝 | 排序前移除，不消耗空位 |
| T-1 收盘价缺失、非有限或不大于 0 | fail-closed 拒绝 | 排序前移除，不消耗空位 |

负值拒绝日志原因为 `RELATIVE_BUY_BOLL_SLOPE_NEGATIVE`；无效输入原因为
`RELATIVE_BUY_BOLL_SLOPE_INVALID`。初始化日志必须同时包含：

- `build="20260901.3"`；
- `relative_buy_policy="EMPTY_SLOT_BACKFILL"`；
- `relative_buy_boll_slope_policy="T1_NORMALIZED_BOLL_MID_SLOPE_NONNEGATIVE"`；
- `relative_buy_boll_slope_threshold=0.0`；
- `atr_exit_policy="OBSERVE_ONLY"`。

## 3. 影响边界

允许变化仅限 `collect_relative_buy_decisions` 中 RELATIVE 新买入资格，且发生在既有
`sort_buy_decisions` 和持仓空位消耗之前。

下列行为必须保持 build `20260828.5` 原样：

- FORMAL BUY 不读取、不要求 BOLL 中轨斜率；
- 已有持仓不因斜率被主动卖出或换仓；
- `SIGNAL_EXIT`、挂起退出、ATR 计算和 `ATR_EXIT_POLICY="OBSERVE_ONLY"`；
- 正式候选优先于相对候选，以及支持数、BOLL 新鲜度、代码的排序键；
- 最大持仓数、目标仓位、ETF 池、订单状态和停牌/未知/未成交语义；
- T-1 日线决策边界、2019--2021 训练窗口和 2018 只读 warm-up；
- manifest、日志身份、源文件不变性和 fail-closed 审计。

不得读取 T 日成交量、价格或其他执行字段来修改斜率资格；不得读取验证期结果调参。

## 4. 聚宽运行顺序

1. 先做短区间冒烟，只核对初始化身份、无未来数据错误和拒绝日志。
2. 再用候选源码全文运行 2019--2021 普通摩擦训练回测，初始资金、回测日期、ETF 池、
   频率和成本口径必须与归档 `.5` 普通摩擦日志一致。
3. 不强制平仓，不以期末未平仓交易美化胜率或收益。
4. 普通摩擦未通过即拒绝本候选，不搜索阈值、不组合量比，也不运行双倍摩擦。
5. 普通摩擦全部通过后，双倍摩擦仅作为下一阶段压力测试，需另行确认后运行。

## 5. 普通摩擦验收门槛

候选与归档 `20260828.5` 普通摩擦基线按同一真实交易路径口径比较。采用必须同时满足：

1. 总收益不低于 `.5`，已平仓交易胜率严格高于 `.5`，且候选胜率 Wilson 95% 下界
   不低于 `.5` 的点估计胜率。
2. 最大回撤严格低于 `.5`，并且小于 15%。
3. 已平仓交易数和实际买入成交数均不少于 `.5` 的 80%。
4. 2019、2020、2021 各年收益均为正；至少两个年度不低于 `.5`；任何年度不得落后
   `.5` 超过 2 个百分点。
5. 按已平仓交易净利润计算的 Top1、Top3 和 Top10% 毛利润集中度均不得高于 `.5`。
6. 期末未平仓数量不得多于 `.5`，最差单笔交易不得劣于 `.5`。
7. 平均现金比例和低于最大持仓数的交易日占比均不得高于 `.5`，避免过滤后长期闲置。
8. 每笔实际成交的 RELATIVE BUY 都必须能由同日 T-1 `signal_snapshot` 证明归一化斜率
   有限且不小于 0；FORMAL BUY 不受该审计条件限制。

任何一项失败都按预注册规则拒绝候选。不得因单项胜率改善而忽略收益、回撤、交易数量、
年度稳定性、利润集中度或期末未平仓恶化。

## 6. 本地验证边界

本地单元测试只证明代码合同，包括阈值边界、无效输入 fail-closed、FORMAL 隔离、排序前
过滤和候选身份日志；它不证明聚宽收益改善，也不构成候选采用结论。
