# 三项支持新买入候选预注册

- 候选 build：`20260901.2`
- 唯一父版本：commit `adcb020f9e0109a54c037070c9c9f17c4cc710db`、build `20260828.5`

- 独立性：不得叠加 build `20260831.2` 的量比软优先候选。

## 单变量假设

所有 FORMAL 和 RELATIVE 新买入候选必须由 T-1 已冻结事件同时获得 `BOLL`、`RSI`、`KDJ` 三项支持。只有两项支持的共振仍可形成观察记录，但不得进入新买入队列。

固定路径归因仅用于提出候选，不能预测启用规则后的真实胜率或收益。过滤买单会改变现金、空位、相对 BUY 补位和后续持仓路径，最终结论必须来自新的聚宽训练期回测。

## 影响边界

唯一允许变化：

- FORMAL 与 RELATIVE 新买入资格；
- 不满三项支持时记录 `ALL_THREE_ENTRY_REQUIRED` 拒绝原因。

必须保持不变：

- 正式和相对事件计算、候选内排序、仓位比例及标的池；
- 当前相对 BUY 空位补位机制；
- 已有持仓处理和全部卖出路径；
- `ATR_EXIT_POLICY="OBSERVE_ONLY"`；
- T-1 日线决策边界、2019-2021训练期和2018只读warm-up边界；
- manifest、日志身份、源文件不可变和fail-closed验证。

不得扩散到：

- T日行情对信号、排序、仓位或卖出决策的修订；
- `volume_ratio`过滤、排序或阈值搜索；
- 验证期数据调参；
- 任何其他策略。

## 普通摩擦验收

与 build `20260828.5` 普通摩擦基线比较，候选必须整体满足：

- 总收益率高于 `66.0665%`；
- 已平仓交易胜率高于 `75.7576%`，Wilson 95%下限不低于 `64.1909%`；
- 最大回撤低于 `15.9334%`，目标低于 `15%`；
- 已平仓交易不少于53笔，全部入场不少于56笔；
- 全交易日日胜率高于 `51.23%`，排除平盘日后高于 `53.74%`；
- 三个年度均为正收益，至少两个年度不低于基线，任一年度不得比基线恶化超过2个百分点；
- 前1、前3和前10%盈利交易占总毛利润的比例不得上升；
- 分别去除前1、前3和前10%盈利交易后的净利润不得低于基线；
- 前1及前3亏损集中度不得上升，最差单笔不得差于约 `-14.0496%`；
- 期末未平仓不得超过3笔。

普通摩擦未全部通过时直接拒绝候选，不进行双倍摩擦。普通摩擦通过后，双倍摩擦仅作为单独的稳健性门禁，不得用于反向调参。

## 本地验证边界

本地测试只验证代码契约、T-1边界和目标/非目标行为，不能证明收益、胜率、日胜率、回撤或利润集中度改善。以上表现指标以聚宽回测为唯一权威依据。
