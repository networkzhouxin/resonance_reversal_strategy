# 固定 3% 止盈候选

## 研究身份

- 当前保留基线：build `20260902.3`，策略行为提交 `350e3dd`
- 候选 build：`20260902.4`
- 处理阶段：`CANDIDATE_AWAITING_JOINQUANT_REPLAY`
- 唯一变量：09:35 当前价相对实际持仓均价达到或超过 3% 时清仓
- 普通摩擦状态：`NOT_RUN`
- 双倍摩擦状态：`DEFERRED_NOT_RUN`
- 验证期状态：`CLOSED_NOT_READ`

本候选是从 `.3` 派生的单变量卖出实验。代码、本地测试和历史固定路径归因都不能证明
真实收益改善；现金、空位、后续 FORMAL/RELATIVE 买入和成交路径会因提前卖出而改变，
最终只接受 JoinQuant 的全路径回测结果。

## 唯一规则

每日 09:35，对策略管理且实际数量大于零的持仓计算：

```text
return_rate = last_price / position.avg_cost - 1
if return_rate >= 0.03:
    order_target(code, 0), reason=TAKE_PROFIT_EXIT
```

规则同时覆盖由 FORMAL 和 RELATIVE 买入形成的持仓，因为退出对象是实际持仓，而不是
入场信号类别。它不主动筛选新买入，不改变原信号卖出，不要求卖出共振，也不使用 T 日
价格重算任何日线指标。

## 影响边界与保护项

允许变化：

- 新增 `TAKE_PROFIT_EXIT`；
- 止盈触发日可能提前清空持仓并释放后续交易日的槽位；
- 当日同时满足止盈和正式 SELL 时，止盈先执行且不得重复下单；
- 停牌、部分成交或未成交时冻结止盈原因，下一交易日无条件优先重试。

必须保持不变：

- 三指标 FORMAL/RELATIVE 新买入资格、正式优先和相对 BUY 空位补位；
- DMI 负向优先及其后既有稳定排序；
- 正式 SELL 信号、仓位、资金、ETF 池和同日回购保护；
- `ATR_EXIT_POLICY="OBSERVE_ONLY"`；
- T-1 日线决策边界、2018 只读预热/日历证据和 2019—2021 训练窗口；
- manifest、日志身份、源文件不可变和 fail-closed 审计。

明确排除：最长持有 5 个交易日、盘中连续监控、分批止盈、移动止盈、相邻阈值搜索、
ETF 特例、验证期调参和双倍摩擦先行。

## 普通摩擦预注册验收

控制组固定使用已归档的 `resonance-20260902.3-standard.log`，SHA-256 为
`47af385cdf55a99431a3604ef5d5c9d2df1a0d614f82c157a84141b5731a17c6`。其日志复算基线为：

| 指标 | `.3` 基线 |
|---|---:|
| 总收益 | 77.1940% |
| 已平仓交易 | 71 |
| 手续费后胜/负 | 53/18 |
| 手续费后胜率 | 74.6479% |
| 日胜率（含零收益日） | 51.2329% |
| 最大回撤 | 15.88318% |
| 中位交易收益 | 2.4811% |
| 前 3 笔毛利润占比 | 21.3898% |
| 期末未平仓 | 3 |

候选报告必须至少包含真实路径总收益、胜/负和胜率、日胜率、最大回撤、已平仓交易数、
2019/2020/2021 分年净利润与胜率、中位交易收益、前 1/3 笔毛利润占比、期末未平仓及
所有退出原因数量。不得把期末未平仓并入胜率，也不得用聚宽页面胜率替代手续费后成交
配对口径而不说明差异。

下列任一项成立即拒绝候选，不进入采用讨论：

1. 手续费后胜率未严格高于 `74.6479%`；
2. 总收益低于 `74.1940%`，即相对基线下降超过 3 个百分点；
3. 最大回撤高于 `15.88318%`；
4. 已平仓交易少于 65 笔；
5. 任一年度净利润不为正，或任一年度胜率相对基线下降超过 5 个百分点；
6. 日胜率低于 `51.2329%`；
7. 前 3 笔毛利润占比高于 26%，或中位交易收益不为正；
8. 期末未平仓超过 3 只；
9. 初始化 build、止盈策略/阈值、参数、ETF 池、事件指纹、T-1 日期、订单状态或持仓
   账本任一项未通过 fail-closed 校验。

全部硬门槛通过只代表可以综合讨论，并不自动采用。若总收益低于 `.3` 但仍在容忍带内，
必须明确量化胜率和回撤改善是否足以补偿收益损失，并再次取得用户确认。普通摩擦失败时
不运行双倍摩擦；普通摩擦通过后，再由用户决定是否补做双倍摩擦。

1. 将候选策略完整复制到聚宽，先做短区间冒烟，核对 build `20260902.4`、
   `take_profit_policy=CURRENT_PRICE_VS_POSITION_AVG_COST` 和 `take_profit_rate=0.03`。
2. 只运行 2019-01-01 至 2021-12-31 普通摩擦；2018 仅用于平台可得的历史预热。
3. 保存原始日志字节、SHA-256 和聚宽收益概述，不修改日志后再归档。
4. 按上述冻结口径与 `.3` 做真实路径比较；不读取验证期，不现场调整 3% 阈值。
