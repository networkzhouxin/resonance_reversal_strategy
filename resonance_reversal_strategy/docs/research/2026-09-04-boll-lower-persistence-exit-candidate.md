## 唯一候选规则

T 日 09:35 对持仓读取截止 T-1 的完整日线。如果 T-2 与 T-1 的收盘价均严格低于
各自交易日计算出的 BOLL(20,2) 下轨，则允许新增结构失效卖出：

```text
close[T-2] < boll_lower[T-2]
and
close[T-1] < boll_lower[T-1]
```

等于下轨不触发；单日跌破不触发；盘中最低价跌破但收盘收回不触发；不得使用 T 日
收盘、最高、最低或成交量修正判断。策略仍在 T 日 09:35 按原执行路径下单。

该规则不是“价格触碰上轨后回落”的获利退出，也不是止盈、固定止损、最长持有期、
中轨跌破或趋势指标组合。513880 的历史案例只用于提出问题，不作为单笔交易反推规则
或验收门槛的依据。

## 控制流真值表

| 正式 SELL | 连续下轨失效 | 既有挂单/保护 | 结果 |
|---|---|---|---|
| 是 | 任意 | 无阻断 | 继续使用 `SIGNAL_EXIT`，正式信号优先 |
| 否 | 否 | 任意 | 不新增卖出 |
| 否 | 是 | 当日刚买入 | 最短持有保护，不卖出 |
| 否 | 是 | 当日已卖/已重试 | 不重复提交 |
| 否 | 是 | 已有挂起退出 | 保留原挂单，不覆盖 |
| 否 | 是 | 停牌 | 冻结为 `BOLL_STRUCTURE_EXIT` 挂单，后续走原重试流程 |
| 否 | 是 | 可交易 | 提交 `BOLL_STRUCTURE_EXIT` |

只运行 2019-01-01 至 2021-12-31 冻结训练期；2018 只作为指标预热和交易日历。
与 build `20260902.3` 相同初始资金、ETF 池、滑点和佣金。不得先查看验证期，也不得
搜索相邻天数、BOLL 参数、百分比阈值或叠加 MACD/ADX 等第二变量。

基线日志复算参考：总收益 `77.1940%`，71 笔已平仓，53 胜 18 负，手续费后胜率
`74.6479%`，日胜率（含零收益日）`51.2329%`，最大回撤 `15.88318%`，中位交易收益
`2.4811%`，前 3 笔毛利润占比 `21.3898%`，期末未平仓 3 笔。

候选回测后必须完整报告：

1. 真实路径总收益、年化、最大回撤及最大回撤区间；
2. 已平仓交易数量、胜/负、手续费后交易胜率、中位收益和盈亏比；
3. 含零收益日与排除零收益日的日胜率；
4. 2019、2020、2021 各年收益、净利润、胜率和最大回撤；
5. 前 1、前 3、前 5 笔盈利占总毛利润比例；
6. 各 ETF 交易数、净利润和亏损贡献；
7. 期末未平仓数量及浮动盈亏，单列且不得并入已平仓胜率；
8. `SIGNAL_EXIT` 与 `BOLL_STRUCTURE_EXIT` 的笔数、损益和原路径替代关系；
9. 初始化、T-1 日期、成交、订单、持仓账本和源日志哈希的 fail-closed 校验。

进入保留讨论的最低条件预先固定为：

- 最大回撤必须严格低于 `15.88318%`，目标值为不高于 `10%`；
- 日胜率必须严格高于 `51.2329%`；
- 手续费后交易胜率不得低于 `74.6479%`；
- 总收益不得低于 `75.21%`；
- 已平仓交易不少于 50 笔；
- 2019、2020、2021 各年净利润均为正；
- 前 3 笔毛利润占比不得高于 26%；
- 期末未平仓不得超过 3 笔；
- 全部身份与路径校验必须通过。

即使满足最低条件也不自动采用；必须结合收益、回撤、胜率、日胜率和利润集中度做
整体比较并由用户明确确认。普通摩擦任一最低条件失败，则记录为失败候选，不搜索
附近参数，且不运行双倍摩擦。普通摩擦全部通过后，再单独决定是否进行双倍摩擦。
